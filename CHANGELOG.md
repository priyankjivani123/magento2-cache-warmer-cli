# Changelog - Magento 2 Cache Warmer CLI

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-09
### Added
- Multi-threaded asynchronous cURL crawler (`curl_multi_init`).
- Automated URL discovery across Catalog Products, Categories, and CMS Pages.
- Sitemap.xml parsing fallback for high-throughput crawling.
- Interactive Symfony Console progress bar and performance metrics reporting table.
- Automated PHPUnit unit tests for URL normalization and concurrency limits.
- PHP 8.1 - 8.4 compatibility verified.
